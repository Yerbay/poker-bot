# Покерный помощник

Telegram-бот и Mini App для Texas Hold'em: считает вероятность выигрыша по картам на руках и на столе.

## Возможности

- Карты отмечаются одним нажатием в сетке из 52 кнопок, число игроков меняется кнопками.
- Вероятность выигрыша: симуляция Монте-Карло на [eval7](https://pypi.org/project/eval7/).
- Диапазоны рук соперников: против любых, средних или крепких рук.
- Подсчёт аутов.
- Можно прислать банк и ставку: бот скажет, выгоден ли колл.
- Mini App с проверкой подписи данных Telegram (HMAC).

## Как устроено

| Файл | Что делает |
|---|---|
| `poker_bot.py` | Бот и API для Mini App на aiohttp; расчёты идут в отдельных процессах |
| `engine.py` | Движок: Монте-Карло, диапазоны рук, ауты |
| `build_preflop.py` | Предрасчёт префлоп-таблицы: 169 стартовых рук × 1–9 соперников × диапазоны |
| `webapp/index.html` | Интерфейс Mini App |

## Запуск

```bash
python -m venv venv && . venv/bin/activate
pip install -r requirements.txt
python build_preflop.py    # один раз, создаёт preflop.json (занимает десятки минут)
BOT_TOKEN=... WEBAPP_URL=https://.../poker/ python poker_bot.py
```

`.env.example` показывает все настройки. `poker-bot.service` — пример сервиса systemd.
